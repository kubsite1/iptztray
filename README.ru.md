# IPTzTray

**Часовой пояс Windows и DNS по внешнему IP, в том числе при включённом VPN.**

Название: IP + Tz (time zone, часовой пояс) + Tray (трей Windows).

## Коротко

IPTzTray ставит часовой пояс Windows по внешнему IP — адресу, через который реально выходит трафик. Включили VPN из другой страны — часовой пояс переключился на страну выхода. Вернулись к домашнему IP — часовой пояс снова домашний. По желанию программа ещё закрывает утечку DNS мимо туннеля, из-за которой при включённом VPN провайдер видит имена сайтов.

Меняется только часовой пояс, сами часы (время UTC) не переводятся. На экране другое местное время, и его же показывают сайты, программы и сервисы.

Так программа убирает два заметных признака VPN: местное время не совпадает с IP, а DNS-запросы идут мимо туннеля. Другие признаки, например IP датацентра или язык системы, она не трогает.

Программа видит IP всей системы. Прокси, включённый только в браузере, она не замечает.

Бесплатно для любого использования. Условия для форков — в разделе «Лицензия и имя».

## Зачем

- Сайты, программы и сервисы показывают домашнее время, хотя трафик уже идёт из другой страны.
- VPN выключен, а часовой пояс так и остался чужим.
- Windows ставит часовой пояс по ближайшей сети Wi‑Fi, а не по IP, через который идёт трафик.
- При включённом VPN Windows продолжает спрашивать DNS у роутера. Запрос уходит мимо туннеля, провайдер видит имена сайтов.

Первые три пункта решает подстройка часового пояса, четвёртый — защита от утечки DNS.

- Вероятно, это может помочь от блокировки аккаунтов Claude (Anthropic) и других вендоров агентской разработки на основе ИИ.

## Как начать

Нужна Windows 10 или 11, 64-бит. Устанавливать ничего не надо: программа — один файл [IpTzTray.exe](https://github.com/kubsite1/iptztray/releases/latest/download/IpTzTray.exe), до 250 КБ. Все версии — на странице [Releases](https://github.com/kubsite1/iptztray/releases).

1. Скачайте и запустите `IpTzTray.exe`.
2. Разрешите права администратора: без них Windows не даёт менять часовой пояс.
3. В трее появится значок, дальше часовой пояс подстраивается сам.

При первом запуске программа запоминает текущий часовой пояс как домашний и включает свой автозапуск при входе в Windows. При каждом запуске с правами администратора она выключает автоматическую установку часового пояса Windows (служба `tzautoupdate`), иначе Windows ставит часовой пояс по ближайшему Wi‑Fi и расходится в значении с программой.

Если в правах отказать, значок будет, но часовой пояс меняться не будет. В меню останется пункт «Запустить с правами администратора».

При выходе из программы и при завершении сессии Windows возвращается домашний часовой пояс, даже если автосмена на паузе. Это можно выключить в настройках.

## Утечка DNS

По умолчанию проверка выключена. Включается в настройках.

Программа смотрит, спрашивает ли Windows DNS не только у туннеля, но и у другого включённого адаптера, чаще всего у роутера. Виртуальные адаптеры, Bluetooth и TAP в проверку не входят. Проверка — один запрос случайного имени `.invalid` на этот DNS. Если он отвечает, пока в Windows включён параллельный опрос DNS, имена сайтов могут уходить мимо VPN.

![Окно утечки DNS](screenshots/dns.png)

Когда утечка видна, программа показывает это окно. Крестик и «Не сейчас» ничего не меняют. «Исправить» на время VPN:

- выключает параллельный опрос DNS в Windows;
- запоминает DNS бокового адаптера и подставляет вместо него DNS туннеля;
- режет исходящие запросы к старому DNS и к известным публичным DNS, в том числе DNS-over-TLS и DNS-over-HTTPS;
- направляет все имена в DNS туннеля.

На домашней сети всё возвращается как было.

Режимы:

- **Не проверять** — снимает уже включённую защиту и возвращает прежние настройки.
- **Один раз при запуске** — спрашивает, только если утечка есть в этот момент. VPN, включённый позже, сам не проверяется.
- **Следить и исправлять само** — исправляет без вопроса при каждом включении VPN и возвращает настройки дома.

VPN для этой функции считается включённым, когда основной маршрут идёт через туннельный адаптер, WireGuard, Amnezia или TAP. Смена часового пояса от этого не зависит: она смотрит только внешний IP. Если адаптер VPN не похож ни на один из этих, часовой пояс всё равно переключится, а DNS программа может сама не поправить.

После исправления программа перезапускает службу DNS. Если интернет пропал, перезагрузите компьютер. Иногда изменение начинает работать только после перезагрузки.

На стороннем тесте утечки может остаться DNS самого VPN, например Cloudflare в стране выхода. Это DNS туннеля, а не домашнего роутера.

## Справочник

### Меню

![Меню](screenshots/menu.png)

Три серые строки сверху: место, IP с именем часового пояса IANA, текущий часовой пояс Windows. Если текущий часовой пояс не совпадает с часовым поясом IP, в третьей строке видны оба. Длинная строка обрезается, полный текст — во всплывающей подсказке.

- **Проверить сейчас** — внеочередная проверка IP.
- **Пауза автосмены** — проверки идут, часовой пояс не меняется. «Продолжить автосмену» снимает паузу и сразу подстраивает часовой пояс.
- **Вернуть домашний пояс** — ставит запомненный домашний часовой пояс и включает паузу, иначе следующая проверка IP сразу его перебьёт.
- **Снять закрепление** — виден, только если для текущего IP есть закрепление (см. «Настройки»).
- **Исправить утечку DNS** — виден, только если утечка уже найдена.
- **Запустить с правами администратора** — виден, только если прав нет.
- **Копировать IP** — копирует внешний IP в буфер обмена.
- **Настройки**, **О программе**, **Выход**.

### Настройки

![Настройки](screenshots/settings.png)

- **При выходе возвращать домашний пояс** — включено по умолчанию.
- **Запомнить текущий пояс** — сразу делает текущий часовой пояс домашним.
- **Запускать при входе в Windows** — задание планировщика `IpTzTray` с правами администратора, без повторного запроса прав. Снятие галочки удаляет задание.
- **Сколько ждать ответ сервиса** — 5, 10 или 20 секунд, по умолчанию 5. Это предел на каждый шаг: отдельно на проверку IP и отдельно на запрос часового пояса.
- **Утечка DNS** — три режима из раздела «Утечка DNS».
- **Язык** — по умолчанию язык Windows. Если его нет в списке, английский. «Сохранить» применяет язык сразу, без перезапуска.

Языки интерфейса: English, 中文, हिन्दी, Español, العربية, Français, বাংলা, Português, Русский, Bahasa Indonesia. Имена часовых поясов показывает Windows, поэтому они на языке системы.

Внизу окна — путь к папке `%AppData%\IpTzTray` и кнопка «Открыть». В папке лежат `settings.json` и журнал `log.txt`. Журнал пишется по-русски. Когда файл вырастает, прошлая часть сохраняется в `log.txt.old`.

**Закрепление** — свой часовой пояс для конкретного IP. Пока оно есть, программа ставит для этого IP указанный часовой пояс и не спрашивает сервис геолокации. Окна для закрепления в этой версии нет. Его можно вписать в `settings.json` при закрытой программе, в поле `Pins`:

```json
"Pins": { "203.0.113.10": "Eastern Standard Time" }
```

Часовой пояс указывается по имени Windows. Список имён печатает команда `tzutil /l`.

### Командная строка

- `IpTzTray.exe --check` — печатает IP и часовой пояс, ничего не меняет.
- `IpTzTray.exe --dns` — печатает, видна ли утечка DNS, ничего не меняет.
- `IpTzTray.exe --dry` — трей в режиме просмотра: часовой пояс и DNS не меняются, настройки пишутся во временную папку.
- `IpTzTray.exe --map Europe/Amsterdam` — печатает часовой пояс Windows для имени IANA.
- `IpTzTray.exe --selftest` — проверяет карту часовых поясов, разбор ответов и сохранение настроек, систему не меняет.

## Как это работает

- **Внешний IP** спрашивается сразу у трёх сервисов: Cloudflare (`1.1.1.1`), ipinfo.io и ip-api.com. Берётся адрес, который назвали хотя бы два. Ответ одного сервиса принимается, только если остальные молчат. Если ответы разошлись, проверка повторяется. Частные адреса отбрасываются.
- **Частота**: пока IP тот же, проверка идёт примерно раз в 10 секунд. После смены сети первая проверка через 5 секунд, дальше около 25 секунд каждые 5 секунд, потом снова раз в 10 секунд.
- **Часовой пояс** спрашивается по очереди у ip-api.com, ipwho.is, ipinfo.io и geojs.io, только когда IP сменился. Имя часового пояса IANA переводится в часовой пояс Windows по таблице Unicode CLDR и ставится командой `tzutil`.
- **Домашний часовой пояс** — часовой пояс Windows при первом запуске, до первой подстройки. Если тогда уже стоял чужой часовой пояс, запомнится он. Исправить можно кнопкой «Запомнить текущий пояс».
- **Что уходит наружу**: внешний IP виден сервисам определения IP при каждой проверке. На сервис геолокации IP уходит только при смене адреса.

## Ограничения

- Прокси, включённый только в браузере, программа не замечает: она видит IP всей системы.
- Город датацентра VPN в базе геолокации иногда не совпадает с нужным часовым поясом. Ставится тот часовой пояс, который вернул сервис.
- Без прав администратора часовой пояс и DNS не меняются.

## Сборка

C#, Windows Forms, .NET Framework из состава Windows, x64. Нужен только компилятор `csc`, он входит в Windows. Visual Studio не нужна.

```
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат: `publish\IpTzTray.exe` и значок `publish\app.ico`.

- `src` — исходный текст.
- `data/windowsZones.xml` — таблица часовых поясов Unicode CLDR.
- `build.ps1` — сборка.
- `app.manifest` — манифест Windows.

Программа написана и собрана с Grok 4.7.
